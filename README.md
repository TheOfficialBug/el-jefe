# El Jefe Authentic Mexican Cuisine — website

Static website for El Jefe, 524 Lincoln Way, Ames, IA 50010. Plain HTML, CSS and a little JavaScript, generated by a dependency-free Node script.

## Pages

| URL | Page |
| --- | --- |
| `/` | Home: hero, fan favorites, menu categories, specials, about |
| `/menu/` | Starters: appetizers, dips, soups, salads |
| `/menu/lunch/` | Lunch favorites, $10 lunch combos, lunch burritos |
| `/menu/chef-favorites/` | Chef favorites, molcajetes, chicken |
| `/menu/steaks-fajitas/` | Dinner combos, steaks, fajitas, enchiladas |
| `/menu/burritos-quesadillas/` | Burritos, quesadillas |
| `/menu/seafood-desserts/` | Seafood, desserts & sides |
| `/bar/` | Bar specials and margaritas |
| `/bar/drinks/` | Micheladas, beer, cocktails, wine & liquor, soft drinks |
| `/visit/` | Map, directions, hours, contact, reservation request, pickup |

## Run it

Requires Node 18 or newer. There is nothing to install.

```bash
npm run preview   # builds to dist/ and serves http://localhost:4173
npm run build     # builds to dist/ only
```

Set `SITE_URL` when building for production so canonical links and the sitemap use the real domain (default: `https://eljefeauthenticmexicancuisine.com`). If the site is served from a sub-path (like a GitHub Pages project site at `/el-jefe/`), also set `BASE=/el-jefe`.

## Editing the menu

Everything on the menu pages comes from **`src/menu.mjs`**: names, descriptions, prices, NEW badges and photos. Change a line there and rebuild.

- Photos live in `public/img/` and are referenced by file name without `.jpg`. An item with no photo shows a "Photo coming soon" plate; drop a square JPG into `public/img/` and add its name to the item.
- Restaurant details (address, phone, email, hours, map links) are at the top of `src/menu.mjs`.
- To show an **Order Online** button on the Visit page, set `orderOnlineUrl` in `src/menu.mjs`.

## Features

- Every menu item as a photo card with price and an "add to order list" button. The order list is saved in the guest's browser and ends with a call-to-order button. No payments are taken.
- Reservation form that opens the guest's email app addressed to hi@eljefeauthenticmexicancuisine.com. To post to a form service instead, add `data-endpoint="https://…"` to the form in `build.mjs`.
- Real map of 524 Lincoln Way (OpenStreetMap), Google Maps and Apple Maps directions links.
- Restaurant structured data (schema.org), Open Graph tags, sitemap.xml and robots.txt.
- Mobile navigation, keyboard focus styles, reduced-motion support.

## Deploying

Upload the contents of `dist/` to any static host (GitHub Pages, Netlify, Cloudflare Pages, or the existing web host).

- **Netlify / Cloudflare Pages:** build command `npm run build`, publish directory `dist`.
- **GitHub Pages:** the included workflow in `.github/workflows/deploy.yml` builds and publishes on every push to `main` (enable Pages → Source: GitHub Actions in the repo settings).
